# Big O Trainer

Pot-limit Big O (5-card Omaha hi-lo 8-or-better) trainer that runs in the browser.

Play at **https://coldbrewtroll.github.io/big-o-trainer/**: no install, no account.

- Play 2-7 handed against fish, nits, maniacs and regs, with 30-200bb stacks.
- An EV coach grades every decision and Explain says why.
- Equity quiz, matchup and calculator tabs, plus a postflop solver.

The whole app is the single file `index.html`; you can also download it and open it locally in Chrome or Edge.
